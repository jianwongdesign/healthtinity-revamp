我应该提早多久到达？

请至少在课程开始前 10 分钟到达，以便有足够时间签到和准备。为了安全及避免干扰课程，迟到者可能会被拒绝入场。被拒绝入场将视为迟取消或缺席。

Healthtinity 的取消政策是什么？

您必须在课程开始前至少五小时透过应用程序取消预约。在课程开始前五小时内取消，将被视为迟取消。

我是初学者，应该选择哪一堂课？

我们非常欢迎初学者！请查看课程介绍，选择适合您目前经验与体能水平的课程。如果不确定，欢迎在预约前联系我们，我们的团队会帮您挑选合适的课程。
