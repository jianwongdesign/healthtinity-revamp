瑜伽哲学

瑜伽历史；吠陀、奥义书、薄伽梵歌与帕坦伽利瑜伽经；三德、五鞘、生命能量与三种体质；瑜伽四大路径与八支瑜伽。

体式练习与顺位

体式与顺位练习、冥想、呼吸法、辅助调整、辅具运用、体式变化，以及阿斯汤加初级序列。

解剖学与教学理论

人体解剖学、生物力学与生理学；课程编排、专项教学及职业发展。

教学技巧

循序渐进的流瑜伽编排、教案设计、课堂结构、声音与语言运用，以及口头和非口头引导。

评估方式

理论考试、实操考试及作业。

阴瑜伽与修复练习

阴阳原理、20 多种阴瑜伽体式、体式调整与课堂编排；经络理论、触发点与筋膜放松。

深化个人练习

解剖、哲学与反思

教学与课堂带领
